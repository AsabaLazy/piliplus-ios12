# PiliPlus (iOS 12)

iOS 12.2–12.5.7 compatibility build of bggRGjQaUbCoE/PiliPlus. Built with AI-assisted coding.

English | [简体中文](README.zh-CN.md)

## Install

1. Download `PiliPlus_*_ios12_unsigned.ipa` from [Releases](https://github.com/AsabaLazy/piliplus-ios12/releases), or build from source via the GitHub Actions workflow.
2. On jailbroken iOS 12.2–12.5.7 devices, install AppSync Unified from Cydia or Sileo and install the IPA with Filza or ideviceinstaller.
3. On non-jailbroken devices, sign and install the IPA using Sideloadly, AltStore, or zsign with a personal Apple ID or developer certificate.

## Description

PiliPlus (iOS 12) builds [bggRGjQaUbCoE/PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus) for 64-bit iOS 12 devices (iPhone 5s, iPhone 6 / 6 Plus, iPhone 6s / 6s Plus, iPad Air 1, iPad mini 2 / 3, and iPod touch 6).

## Compatibility

Includes a patched Flutter 3.47+ iOS 12 engine, dyld2-compatible App.framework relinking, libmpv / FFmpeg video decoding libraries, and Objective-C runtime shims for iOS 13+ Metal, UIScene, and UIKit APIs.

## Build Pipeline

Scheduled GitHub Actions workflows track upstream releases and build packages using [AsabaLazy/oldcook](https://github.com/AsabaLazy/oldcook). This project is developed with AI-assisted coding.
